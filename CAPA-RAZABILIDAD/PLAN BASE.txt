# MASTER PROMPT — FOXIT CRIMINAL JUSTICE DOCUMENT TRACEABILITY MVP

Actúa como un **Senior Product Architect, Full-Stack Engineer, Document Management Specialist and Foxit API Integration Engineer**.

Quiero que me ayudes a diseñar y planificar un MVP que será presentado al equipo directivo de **Foxit** como parte de una propuesta para desarrollar un proyecto utilizando sus tecnologías de PDF, document processing, e-signature, document generation y/o Foxit MCP Server.

El objetivo NO es construir un sistema judicial completo. El objetivo es demostrar, mediante un MVP pequeño pero técnicamente sólido, cómo las tecnologías de Foxit podrían aportar una **capa de integridad, trazabilidad y gestión documental** sobre un flujo existente de justicia penal.

---

# 1. CONTEXTO DEL PROYECTO

El proyecto está pensado inicialmente para Perú y posteriormente podría evaluarse su adaptación a otros países de América Latina.

El problema que quiero abordar es la dificultad de mantener la trazabilidad de documentos durante un proceso de justicia penal.

Un documento puede comenzar en la Policía, posteriormente ser enviado al Ministerio Público/Fiscalía y finalmente incorporarse al expediente judicial.

Durante este proceso pueden existir:

* múltiples documentos;
* diferentes versiones;
* correcciones;
* anotaciones;
* firmas;
* transferencias entre instituciones;
* diferentes responsables;
* diferentes fechas y horas;
* documentos PDF generados desde distintas fuentes;
* riesgo de perder claridad sobre quién creó, modificó o transfirió determinada información.

La solución propuesta NO debe reemplazar los sistemas judiciales existentes.

Debe funcionar conceptualmente como una **document traceability layer** que permita preservar y demostrar la integridad y el historial de los documentos.
