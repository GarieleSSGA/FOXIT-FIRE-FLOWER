Stage 1: Document DNA & Cryptographic Sealing at Origin Web Crypto API (SHA-256)

11-column data dictionary synchronized with DataHub (Title B and C of the NSR-10 Standard): 

1.  element_id              [STRING]        Unique element identifier (e.g.: BEAM-V101, COL-C201)
2.  element_type            [STRING]        Structural typology (Beam, Column, Slab)
3.  location_grid           [STRING]        Location on structural plan and floor level
4.  design_capacity_kn_m2   [FLOAT]         Nominal calculated design capacity (kN/m²)
5.  applied_load_kn_m2      [FLOAT]         Actual service load measured in the field (kN/m²)
6.  safety_factor           [FLOAT]         Calculated safety factor = Capacity / Load
7.  material_spec           [STRING]        Concrete specification (MPa) and reinforcement steel
8.  inspection_date         [DATE]          Data collection date (YYYY-MM-DD)
9.  inspector_id            [STRING]        Professional inspector license (ENG-8821)
10. compliance_status       [ENUM]          PASS / FAIL / FLAGGED
11. notes                   [STRING]        Technical observations and calculation notes
